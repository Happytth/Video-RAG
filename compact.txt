| **Groq 400 Invalid Request** | Groq Vision API supports maximum 3 images per request | Restricted fallback payload to `top_frames = image_frames[:2]`. |

### Current Strategy for Finding Unnamed People in Long Videos

Sending all frames at query time crashes API limits. The two optimal strategies for long videos are:

1. **Dense VLM Captioning at Ingestion:** Run a vision model (e.g., `Gemini 2.0 Flash` or `Florence-2`) during Stage 1 to generate detailed text descriptions of people/entities directly into `timeline.json`.
2. **Multimodal Vector Search (CLIP / ImageBind):** Embed keyframes using CLIP during Stage 1 so text queries (e.g., `"Harry Styles"`) match visual image vectors directly in Neo4j, retrieving only the 1–2 relevant frames at query time.
